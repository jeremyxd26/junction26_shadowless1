| 2026-11-13 22:31 | Contract changes notify instead of block: `area:contract` label, a comment mentioning the other person with a three-line summary, merge after reviewer PASS; the other person asks for changes through a new issue (#16) | Owner decision; the other side still sees every contract change and can ask for a fix without holding up the merge |

| 2026-11-13 22:31 | The answer composer is a separate, tool-free model call (#5) | Combining structured output with function calling is a preview feature in the Gemini docs; a separate call works on any current model and gets tool data as a quoted block (R11, R12) |
